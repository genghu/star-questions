题目 1: 独立事件的并集与交集的概率

假设 A 和 B 是独立事件，且 P(A) = 0.20 和 P(B) = 0.40。

求 P(A ∩ B) 和 P(A ∪ B)。

解题思路：

对于独立事件，交集的概率为：P(A ∩ B) = P(A) · P(B) = 0.20 × 0.40 = 0.08

并集的概率为：P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 0.20 + 0.40 - 0.08 = 0.52

题目 2: 补集事件的概率计算

基于题目1的条件，现在计算 P(A̅ ∩ B) 和 P(A̅ ∪ B)。

首先，我们求 P(A̅)，因为后续计算需要用到它。我们可以使用补集法则：

P(A̅) = 1 - P(A) = 1 - 0.20 = 0.80。

由于 A̅ 和 B 是独立的，我们有 P(A̅ ∩ B) = P(A̅) · P(B) = 0.80 · 0.40 = 0.32。

接下来，利用概率加法公式，我们有 P(A̅ ∪ B) = P(A̅) + P(B) - P(A̅ ∩ B) = 0.80 + 0.40 - 0.32 = 0.88。

2. 对于任意两个事件：P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
