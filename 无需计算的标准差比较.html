无需计算的标准差比较

通过观察直方图分布比较离散程度

题目

三个分布，分别标记为 (a)、(b) 和 (c)，由下面的直方图表示。每个分布都由 12 次测量值组成。在不进行任何计算的情况下，对它们各自的标准差 σa、σb 和 σc 进行排序。

本题中的直方图使用方块来表示数据集中的值及其频数。位于某个值上的方块代表一次具有该值的测量。

分布 (a)
分布 (b)
分布 (c)
正确答案: σc < σb < σa

请选择正确的排序

σa < σb < σc
σb < σa < σc
σc < σa < σb
σc < σb < σa
σa < σc < σb
σb < σc < σa

题目解析

第一步：比较 (a) 和 (b) 的标准差。

观察直方图，分布 (a) 的测量值分布在 4-12 之间，而分布 (b) 的测量值分布在 6-10 之间。虽然两者都关于均值8对称，但分布 (b) 的测量值更接近均值。因此，分布 (b) 中的测量值倾向于不那么分散。

所以，σb < σa。

第二步：比较 (b) 和 (c) 的标准差。

观察直方图，分布 (b) 的测量值分布在 6-10 之间，而分布 (c) 的测量值集中在 7-9 之间。分布 (c) 的测量值更接近均值8。因此，分布 (c) 中的测量值倾向于更集中。

所以，σc < σb。

第三步：结合以上两个不等式。

由 σc < σb 和 σb < σa，我们得到：

σc < σb < σa

结论：分布 (c) 的离散程度最小（标准差最小），分布 (a) 的离散程度最大（标准差最大）。
