联合分布下两随机变量概率

交互式答题练习 - 根据联合概率分布表计算随机变量的概率

题目信息

两个随机变量 X, Y 的联合概率分布如下表所示。根据表中的信息，计算以下三个概率。

X \ Y Y 的值 边缘分布 P(X)
-3 0 1 2 4
-3 .17 .06 .00 .00 .14 .37
2 .00 .01 .08 .06 .02 .17
3 .13 .05 .10 .07 .11 .46
边缘分布 P(Y) .30 .12 .18 .13 .27 1.00

提示： 黄色高亮单元格表示在相应题目中需要使用的概率值。

1 计算 P(X ≥ 4)

根据联合分布表，X 的可能取值为 -3, 2, 3。没有 X 的值大于或等于 4。

A
P(X ≥ 4) = 0
B
P(X ≥ 4) = 0.14
C
P(X ≥ 4) = 0.27
D
P(X ≥ 4) = 0.37
正确！因为 X 的可能取值只有 -3, 2, 3，没有大于等于 4 的值，所以概率为 0。

解析

随机变量 X 的所有可能取值在表格的第一列中列出：-3, 2, 3。这些值都小于 4，因此事件 "X ≥ 4" 是不可能事件，其概率为 0。

2 计算 P(X > 2, Y ≤ 2)

需要找出满足 X > 2 且 Y ≤ 2 的所有单元格的概率值并求和。

A
P(X > 2, Y ≤ 2) = 0.11
B
P(X > 2, Y ≤ 2) = 0.35
C
P(X > 2, Y ≤ 2) = 0.46
D
P(X > 2, Y ≤ 2) = 0.30

解析

条件 X > 2 意味着 X = 3（因为只有 3 > 2）。

条件 Y ≤ 2 意味着 Y = -3, 0, 1, 2（因为这些值都 ≤ 2）。

因此，我们需要计算 X=3 且 Y 取 -3, 0, 1, 2 的概率之和：

P(X=3, Y=-3) = 0.13

P(X=3, Y=0) = 0.05

P(X=3, Y=1) = 0.10

P(X=3, Y=2) = 0.07

P(X > 2, Y ≤ 2) = 0.13 + 0.05 + 0.10 + 0.07 = 0.35

3 计算 P(X = -3)

计算 X 在 -3 处的边缘分布，即固定 X = -3 时，对所有 Y 取值求和。

A
P(X = -3) = 0.17
B
P(X = -3) = 0.30
C
P(X = -3) = 0.37
D
P(X = -3) = 0.46

解析

X 的边缘分布是通过对联合分布表中固定 X 值所在行的所有 Y 值求和得到的。

对于 X = -3，我们需要将这一行的所有概率值相加：

P(X=-3, Y=-3) = 0.17

P(X=-3, Y=0) = 0.06

P(X=-3, Y=1) = 0.00

P(X=-3, Y=2) = 0.00

P(X=-3, Y=4) = 0.14

P(X = -3) = 0.17 + 0.06 + 0.00 + 0.00 + 0.14 = 0.37

这也可以直接从表格最右侧的边缘分布列中读取。
