总体均值差异的置信区间t分布应用

置信区间与假设检验 - 两独立样本t区间

题目背景： 某咨询师想要比较两个不同社会群体的平均智商分数。从群体1中随机抽取的16个智商分数样本显示均值为104，标准差为16；同时，从群体2中独立抽取的9个智商分数样本显示均值为116，标准差为14。假设每个群体的智商分数总体服从正态分布，且这些总体的方差相等。
问题：构建90%置信区间
请构建一个关于群体1智商分数均值μ₁与群体2智商分数均值μ₂之差(μ₁ - μ₂)的90%置信区间。将中间计算过程至少保留三位小数。最终答案至少保留两位小数。 已知： n₁ = 16, x̄₁ = 104, s₁ = 16 n₂ = 9, x̄₂ = 116, s₂ = 14 显著性水平 α = 0.10 (90%置信度) 假设两总体方差相等。 计算步骤： 1. 计算合并样本方差 s²_p： s²_p = [ (n₁ - 1)s₁² + (n₂ - 1)s₂² ] / (n₁ + n₂ - 2) = [ (15)*256 + (8)*196 ] / (23) = [ 3840 + 1568 ] / 23 = 5408 / 23 ≈ 235.130 2. 计算标准误： SE = √[ s²_p * (1/n₁ + 1/n₂) ] = √[ 235.130 * (0.0625 + 0.111111) ] = √[ 235.130 * 0.173611 ] = √40.818 ≈ 6.388 3. 确定自由度与t临界值： 自由度 df = n₁ + n₂ - 2 = 23 t_{α/2} = t_{0.05} (df=23) ≈ 1.714 4. 计算均值差： (x̄₁ - x̄₂) = 104 - 116 = -12 5. 计算置信区间： 下限 = (x̄₁ - x̄₂) - t_{α/2} * SE = -12 - (1.714 * 6.388) ≈ -12 - 10.950 ≈ -22.95 上限 = (x̄₁ - x̄₂) + t_{α/2} * SE = -12 + (1.714 * 6.388) ≈ -12 + 10.950 ≈ -1.05
