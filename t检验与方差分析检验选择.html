t检验与方差分析检验选择

一家大型电视网络正在评估几档潜在节目的观众兴趣

背景信息

本题中提到的五种统计检验均可用于对两个或更多总体均值进行推断。您可能熟悉所有这些检验，除了可能不熟悉双因素方差分析检验，它与其他检验的不同之处在于允许考察两个自变量或因素。

选择这些检验的一个重要步骤是确定正在研究多少组。每个不同的实验条件或观察类别对应一个不同的组。

检验选择流程图

正在研究多少组？

两个 → 所有样本测量值是否独立？ → 是 → 独立样本 t 检验或单因素独立样本方差分析

两个 → 所有样本测量值是否独立？ → 否 → 如果样本测量值是配对的，则使用配对样本 t 检验或单因素重复测量方差分析

三个或更多 → 所有样本测量值是否独立？ → 是 → 正在研究多少个自变量（因素）？ → 一个 → 单因素独立样本方差分析

三个或更多 → 所有样本测量值是否独立？ → 是 → 正在研究多少个自变量（因素）？ → 两个 → 双因素（独立样本）方差分析

三个或更多 → 所有样本测量值是否独立？ → 否 → 如果只有一个自变量且样本测量值在各组间相关，则使用单因素重复测量方差分析

1

该网络正在测试两个节目。它试图确定其中一个节目是否比另一个更受欢迎，以及年轻观众（四十岁以下）与年长观众（四十岁及以上）是否有不同的看法。

该网络随机选择 32 名四十岁以下的人和 32 名四十岁及以上的人。它将四十岁以下的人随机分成 16 人一组，并为每组分配一个不同的试播集。该网络对四十岁及以上的人也进行同样的操作。

请选择所有可用于该场景的检验：

A
独立样本 t 检验
B
配对样本 t 检验
C
单因素独立样本方差分析
D
单因素重复测量方差分析
E
双因素（独立样本）方差分析

解析

正在研究四个组：两个电视节目分别在两个年龄类别中进行测试，总共产生 2 × 2 = 4 个实验条件。（这称为析因设计。）请注意，所有样本测量值都是独立的，因为观众被随机分配到这些组。还请注意，正在研究的因素有两个：电视节目和年龄类别。因此，应使用双因素（独立样本）方差分析。

正确答案：E（双因素（独立样本）方差分析）

2

该网络正在测试两个节目。对于每个节目，该网络选择一个不同的 32 人随机样本，并让他们只观看该节目的试播集。

请选择所有可用于该场景的检验：

A
独立样本 t 检验
B
配对样本 t 检验
C
单因素独立样本方差分析
D
单因素重复测量方差分析
E
双因素（独立样本）方差分析

解析

正在研究两个组，每个电视节目对应一个组。每个样本测量值都独立于其他测量值，因为为每个节目选择了不同的观众随机样本。只有一个自变量（因素），即电视节目。因此，可以使用独立样本 t 检验或单因素独立样本方差分析检验。

正确答案：A（独立样本 t 检验）或 C（单因素独立样本方差分析）

3

该网络正在测试四个节目。对于每个节目，该网络选择一个不同的 16 人随机样本，并让他们只观看该节目的试播集。

请选择所有可用于该场景的检验：

A
独立样本 t 检验
B
配对样本 t 检验
C
单因素独立样本方差分析
D
单因素重复测量方差分析
E
双因素（独立样本）方差分析

解析

正在研究四个组，每个电视节目对应一个组。每个样本测量值都独立于其他测量值，因为为每个节目选择了不同的观众随机样本。只有一个自变量（因素），即电视节目。因此，应使用单因素独立样本方差分析。（请注意，不能使用独立样本 t 检验，因为正在研究的组超过两个。）

正确答案：C（单因素独立样本方差分析）
