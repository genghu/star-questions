总体标准差的置信区间

交互式答题练习 - 置信区间与假设检验

题目内容

产品每日需求的标准差是控制该产品库存的一个重要因素。

假设一家药店想要估计某种抗生素每日需求的标准差。已知该抗生素的每日需求近似服从正态分布。一个包含 30 天的随机样本中，该抗生素的样本均值为 124.5 份订单，标准差为 10 份订单。求该抗生素每日需求的总体标准差的 99% 置信区间。

将中间计算过程保留至少三位小数。将答案四舍五入到至少两位小数。

请选择正确答案

A
下限: 7.44, 上限: 14.87
B
下限: 7.20, 上限: 15.10
C
下限: 8.05, 上限: 13.95
D
下限: 6.85, 上限: 16.25

题目解析

我们需要求总体标准差 σ 的 99% 置信区间。我们将先求总体方差 σ² 的 99% 置信区间，然后通过取平方根得到 σ 的置信区间。

样本方差 s² 是我们用来估计 σ² 的量。当 s² 是从正态总体中抽取的容量为 n 的随机样本的方差时，则

(n-1)s² / σ²

近似服从自由度为 n-1 的卡方分布。在此问题中，n = 30，所以

(30-1)s² / σ² = 29 s² / σ²

服从自由度为 29 的卡方分布。我们将使用这个分布来求置信区间。

为了找出自由度为 29 的卡方分布的"中间 99%"，我们使用截取该分布下尾 0.5% 和上尾 0.5% 的数值。这些数值分别是 χ²₀.₉₉₅ 和 χ²₀.₀₀₅。

因此，大约 99% 的来自该总体的容量为 30 的随机样本满足：

χ²₀.₉₉₅ < (30-1)s² / σ² < χ²₀.₀₀₅

解出 σ²，我们看到大约 99% 的来自该总体的容量为 30 的样本满足：

(30-1)s² / χ²₀.₀₀₅ < σ² < (30-1)s² / χ²₀.₉₉₅

或者等价地，

√[ (30-1)s² / χ²₀.₀₀₅ ] < σ < √[ (30-1)s² / χ²₀.₉₉₅ ]

s 的观测值给定为 10，我们可以计算 χ²₀.₉₉₅ 和 χ²₀.₀₀₅（这些计算基于自由度为 29 的卡方分布）。

因此，基于该样本的 σ 的 99% 置信区间为：

( √[ (30-1)*10² / χ²₀.₀₀₅ ] , √[ (30-1)*10² / χ²₀.₉₉₅ ] ) ≈ ( √[ 29*100 / 52.336 ] , √[ 29*100 / 13.121 ] ) ≈ (7.44, 14.87)

一般而言，如果从正态总体中抽取容量为 n 的随机样本，则总体标准差 σ 的 (1-α)100% 置信区间为：

( √[ (n-1)s² / χ²_{α/2} ] , √[ (n-1)s² / χ²_{1-α/2} ] )

其中 s 是样本标准差，χ²_{1-α/2} 和 χ²_{α/2} 分别是自由度为 n-1 的卡方分布中截取左尾和右尾 α/2 面积的数值。
