离散概率分布基础

交互式概率分布练习 - 填写缺失的概率值

题目

在下表中填入数值，为离散随机变量 X 给出一个合法的概率分布，其可能取值为 2, 3, 4, 5, 6。

X 的取值 x P(X = x)
2 0.17
3 0.23
4
5 0.29
6
约束条件

离散随机变量 X 的可能取值为 2, 3, 4, 5, 6。因此，必须满足：

P(X=2) + P(X=3) + P(X=4) + P(X=5) + P(X=6) = 1

且对于 x = 2, 3, 4, 5, 6，有 0 ≤ P(X = x) ≤ 1。

根据所给信息，我们有：

0.17 + 0.23 + P(X=4) + 0.29 + P(X=6) = 1

这意味着：

P(X=4) + P(X=6) = 1 - (0.17 + 0.23 + 0.29) = 0.31

为了完成这个概率分布，我们必须选择 P(X=4) 和 P(X=6) 为 0 到 1 之间的任意数，使得 P(X=4) + P(X=6) = 0.31。

示例解答

例如，我们可以选择 P(X=4) = 0.08 且 P(X=6) = 0.23。

一个正确答案是：

X 的取值 x P(X = x)
2 0.17
3 0.23
4 0.08
5 0.29
6 0.23

答案解析

要创建一个合法的概率分布，所有概率值必须在0到1之间，且所有概率之和必须等于1。

根据给定的约束条件：P(X=4) + P(X=6) = 0.31

一个正确答案是：P(X=4) = 0.08, P(X=6) = 0.23
