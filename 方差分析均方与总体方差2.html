方差分析均方与总体方差

根据题目内容，计算并回答以下问题

1题目内容

为了应对学生作弊，一位教授为一个大班创建了期中考试的四个版本，并将这四个版本分发给班上的 348 名学生。考试后，班上的 5 名学生聚集在一起，以四个版本的难度不相等为由，请求取消考试结果。

为了调查学生的断言，教授检查了不同版本考试分数的均值和方差，获得了以下信息（考试满分为 200 分）。

组别 样本量 样本均值 样本方差
版本 A 87 152.2 423.0
版本 B 87 155.7 354.4
版本 C 87 158.1 444.7
版本 D 87 154.1 335.2

将每个考试版本的 87 个分数视为该版本分数的一个样本，教授对四个版本的总体平均分数是否相等进行了单因素独立样本方差分析（ANOVA）检验。

请回答以下问题，将中间计算过程至少保留三位小数，并将最终答案至少保留一位小数。

误差均方（组内均方）公式：当所有样本量相同时，误差均方就是样本方差的简单平均值：

误差均方 = 样本方差的平均值

组间均方公式：当所有样本量相同时，组间均方直接基于样本均值的样本方差计算：

组间均方 = (样本量) × (样本均值的样本方差)

2问题1：组内均方

在 ANOVA 检验中报告的"组内"均方值是多少？

提示：计算四个版本样本方差的平均值。

反馈

计算过程：

组内均方（误差均方）= (423.0 + 354.4 + 444.7 + 335.2) / 4

= 1557.3 / 4 = 389.325

保留一位小数：389.3

3问题2：组间均方

在 ANOVA 检验中报告的"组间"均方值是多少？

提示：先计算样本均值的方差，再乘以样本量(87)。

反馈

计算过程：

1. 计算四个样本均值：152.2, 155.7, 158.1, 154.1

2. 计算均值： (152.2 + 155.7 + 158.1 + 154.1) / 4 = 620.1 / 4 = 155.025

3. 计算样本均值的方差：

[(152.2-155.025)² + (155.7-155.025)² + (158.1-155.025)² + (154.1-155.025)²] / (4-1)

= [7.9806 + 0.4556 + 9.4556 + 0.8556] / 3

= 18.7474 / 3 = 6.2491

4. 组间均方 = 样本量 × 样本均值的方差 = 87 × 6.2491 = 543.6717

保留一位小数：543.7
