总体比例假设检验

交互式答题练习 - 根据题目内容完成假设检验
1 原假设：H₀:

一项十年前的研究发现，相信"致富"是重要个人目标的高中毕业生的比例 p 为 70%。一位研究员决定检验这个百分比是否仍然成立。他在其随机抽取的 215 名高中毕业生样本中发现，有 164 人相信"致富"是一个重要目标。

在 0.1 的显著性水平下，他能否得出比例确实已经改变的结论？

执行一个双尾检验。

H₀: p = 0.70
A p = 0.70
B p ≠ 0.70
C p > 0.70
D p < 0.70
2 备择假设：H₁:

由于我们正在寻找证据来确定 p 是否与 0.70 不同，因此假设应表述为：

H₁: p ≠ 0.70
A p = 0.70
B p ≠ 0.70
C p > 0.70
D p < 0.70
3 检验统计量的类型：

此处，样本量 n = 215，样本比例 p̂ = 164/215。

虽然样本计数服从二项分布，但如果 np > 5 且 n(1-p) > 5，则正态近似是合适的。假设原假设为真，我们检验 np = 215 * 0.70 = 150.5 > 5 且 n(1-p) = 215 * (1-0.70) = 64.5 > 5。因此，样本比例具有近似正态分布，期望为 p，方差为 p(1-p)/n。因此，Z = (p̂ - p) / √[p(1-p)/n] 具有近似标准正态分布。所以我们使用 Z 检验统计量。

A Z
B t
C 卡方
D F
4 检验统计量的值（至少四舍五入到三位小数）：

该检验统计量的值是在假设 H₀ 为真的情况下，对应于样本比例的 z 值。即，其值为：

z = (p̂ - p) / √[p(1-p)/n] = (164/215 - 0.70) / √[0.70(1-0.70)/215] ≈ 2.009
A 1.645
B 2.009
C 1.960
D 2.576
5 在 0.1 显著性水平下的两个临界值（至少四舍五入到三位小数）：

由于 H₁ 包含符号 ≠，此假设检验是双尾的，我们有两个临界值。

临界值为 -z_{α/2} 和 z_{α/2}，其中 z_{α/2} 是在标准正态密度曲线右尾截取面积为 α/2 的 z 值。

显著性水平 α = 0.1。因此，四舍五入到三位小数的临界值为 -1.645 和 1.645。

A -1.960 和 1.960
B -1.645 和 1.645
C -2.576 和 2.576
D -1.282 和 1.282
6 我们能否得出结论，相信"致富"是重要目标的高中毕业生的比例已经改变？

由于检验值 2.009 落在临界区域（大于 1.645）内，决策是拒绝原假设。

我们拒绝了 H₀（即旧的比例）。也就是说，我们得出结论，有足够的证据拒绝"恰好有 70% 的高中毕业生相信'致富'是重要的个人目标"这一论断。

A 是
B 否
得分: 0 / 6

答题反馈

题目解析

1. 原假设 H₀: 由于我们要检验比例是否改变（双尾检验），原假设应为比例没有改变，即 p = 0.70。

2. 备择假设 H₁: 由于我们要检验比例是否改变，备择假设应为 p ≠ 0.70。

3. 检验统计量的类型: 对于总体比例的假设检验，当样本量足够大时（np>5且n(1-p)>5），使用Z检验统计量。

4. 检验统计量的值: 计算得 z = (164/215 - 0.70) / √[0.70(1-0.70)/215] ≈ 2.009。

5. 临界值: 显著性水平 α=0.1，双尾检验，临界值为 -1.645 和 1.645。

6. 结论: 由于检验统计量 2.009 > 1.645，落在拒绝域，因此拒绝原假设，得出结论比例已经改变。
