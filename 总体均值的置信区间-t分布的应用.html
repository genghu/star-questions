总体均值的置信区间：t分布的应用

置信区间与假设检验 · 交互式答题练习

题目内容

随机抽取了14个健康维护组织（HMO）。记录每个HMO的医生门诊共付额（美元）。结果如下：

11, 8, 11, 12, 10, 10, 9, 8, 7, 12, 5, 7, 6, 8

假设共付额金额服从正态分布，求总体平均共付额金额（美元）的90%置信区间。

中间计算至少保留三位小数。答案四舍五入到一位小数。

计算步骤与解析

步骤 1: 计算样本均值 (x̄)

样本数据: 11, 8, 11, 12, 10, 10, 9, 8, 7, 12, 5, 7, 6, 8

总和 = 124, 样本量 n = 14

x̄ = 124 / 14 = 8.857 (保留三位小数)

步骤 2: 计算样本标准差 (s)

使用样本标准差公式计算:

s = 2.214 (保留三位小数)

步骤 3: 确定 t 临界值 (tα/2)

置信水平 = 90%，显著性水平 α = 0.10

自由度 df = n - 1 = 14 - 1 = 13

t0.05, 13 = 1.771 (查t分布表)

步骤 4: 计算标准误差

标准误差 = s / √n = 2.214 / √14

√14 ≈ 3.742, 所以标准误差 ≈ 2.214 / 3.742 = 0.592

步骤 5: 计算置信区间

边际误差 = tα/2 × (s / √n) = 1.771 × 0.592 = 1.048

下限 = x̄ - 边际误差 = 8.857 - 1.048 = 7.809

上限 = x̄ + 边际误差 = 8.857 + 1.048 = 9.905

四舍五入到一位小数: (7.8, 9.9)

t分布与置信区间原理

我们感兴趣的是估计总体均值 μ。根据随机样本，我们对 μ 值的估计是样本均值 x̄。当然，这只是一个估计，它可能接近也可能不接近 μ 的真实值。为了了解估计值 x̄ 的精确度，我们可以基于 x̄ 构造一个数值区间，通过一种方法使得该区间有约90%的概率包含 μ。这称为 μ 的置信区间。

t = (x̄ - μ) / (s / √n)

由于总体标准差未知，我们不能使用标准正态分布。统计量 t 服从自由度为 n-1 的 t 分布。

对于我们的样本，n = 14，因此我们使用自由度为 13 的 t 分布。该分布密度曲线下约90%的面积位于 t ≈ -1.771 和 t ≈ 1.771 之间。

x̄ - tα/2 × (s / √n) ≤ μ ≤ x̄ + tα/2 × (s / √n)

总体均值 μ 的 (1-α)100% 置信区间由下式给出：

( x̄ - tα/2 × (s / √n) , x̄ + tα/2 × (s / √n) )

该区间也写作：x̄ ± tα/2 × (s / √n)

重要提示：使用t分布构造置信区间的前提条件是：

  1. 总体服从正态分布，或样本量足够大（中心极限定理）
  2. 总体标准差未知，使用样本标准差估计
  3. 样本是随机抽取的

答案参考

根据计算，90%置信区间为：

(7.8, 9.9)

这意味着我们有90%的把握认为，总体平均共付额金额在7.8美元到9.9美元之间。
