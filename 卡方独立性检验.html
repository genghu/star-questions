关键公式与概念

期望频数计算公式：

第i行第j列单元格的期望频数 = (第i行总计) x (第j列总计) / 样本量

fEij = (RowTotali x ColTotalj) / n

卡方检验统计量：

chi^2 = Sum [ (fO - fE)^2 / fE ]

其中求和遍及列联表中的所有单元格

自由度：

df = (行数 - 1) x (列数 - 1) = (2 - 1) x (4 - 1) = 3

检验原理：如果两个分类变量是独立的，那么在一定条件下，chi^2 近似服从自由度为 (r-1)(c-1) 的卡方分布。chi^2 值越大，观测频数与独立性假设下的期望频数差异越大，两个变量独立性的可能性就越小。
