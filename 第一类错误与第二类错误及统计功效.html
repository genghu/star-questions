第一类错误与第二类错误及统计功效

假设检验交互式练习题 - 餐饮服务业工会工资案例

背景： 一个餐饮服务业工会想要估计今年美国餐饮服务业工人的平均小时工资 μ。去年的平均小时工资是 $8.25，有理由相信今年的数值低于去年。

已知信息： 样本容量 n = 150，总体标准差 σ = $1.25，显著性水平 α = 0.1。

(a) 工会应该用于检验的原假设和备择假设是什么？

H₀: μ

H₁: μ

解析

有理由相信今年的平均小时工资 μ 低于去年的值 $8.25。被检验的陈述是 μ 不小于 $8.25。在进行检验时，工会将暂时假设 μ 不小于 $8.25，并检查观测到的 x̄ 值，看是否可以拒绝这个假设。因此，原假设是 μ 不小于 $8.25，备择假设是 μ 小于 $8.25：

H₀: μ ≥ 8.25，H₁: μ < 8.25

(b) 当原假设实际上为真时，工会拒绝原假设的概率是多少？将你的回答舍入到至少两位小数。
解析

当原假设实际上为真时拒绝原假设是第一类错误。第一类错误的概率总是等于 α，即显著性水平。对于此检验，α = 0.1。

因此，概率为 0.10。

(c) 假设 μ 的实际值是 $8.09，工会拒绝原假设的概率是多少？将你的回答舍入到至少两位小数。
解析

这个概率是检验对于备择值 $8.09 的功效。计算步骤如下：

1. 计算临界值 C = μ₀ + (-z_{0.1}) * (σ/√n) = 8.25 + (-1.2816) * (1.25/√150) ≈ 8.1192

2. 计算当 μ₁ = 8.09 时，x̄ > C 的概率：z = (8.1192 - 8.09) / (1.25/√150) ≈ 0.2861

3. β = P(Z ≥ 0.2861) ≈ 0.3874 ≈ 0.39

4. 功效 = 1 - β ≈ 1 - 0.39 = 0.61

因此，概率为 0.61。

(d) 假设工会决定使用相同的总体、相同的原假设和备择假设、相同的样本容量进行另一次统计检验，但对于这第二次检验，工会使用 0.05 的显著性水平，而不是 0.1 的显著性水平。假设 μ 的实际值是 $8.09，工会在这第二次检验中犯第二类错误的概率与在原检验中犯第二类错误的概率相比如何？
A
第二次检验中犯第二类错误的概率更大
B
第二次检验中犯第二类错误的概率更小
C
犯第二类错误的概率相等
解析

当显著性水平 α 从 0.1 降低到 0.05 时，临界值 C 会向左移动（变得更小），这意味着需要更强的证据才能拒绝原假设。因此，当原假设为假（μ = 8.09）时，不拒绝原假设的概率（即第二类错误的概率 β）会增加。

所以，第二次检验中犯第二类错误的概率更大。
