正态分布与标准正态分布密度曲线

交互式学习模块 - 理解z变换与概率区域对应关系

题目内容

下图是一个均值为 μ = -1、标准差为 σ = 4 的正态分布图。阴影区域表示从该分布中获得一个小于 5 的值的概率。

请在下面的标准正态密度曲线上标出相应的区域。

解题思路

  • 标准正态分布是均值为 0、标准差为 1 的正态分布。
  • 任何值 c 都位于距离分布均值 c 个标准差的位置。
  • 使用 z 变换将原始正态分布的值转换为标准正态分布的 z 分数：
z = (x - μ) / σ

其中 x 是原始分布的值，μ 是均值，σ 是标准差。

计算过程

对于本题：μ = -1, σ = 4, x = 5

z = (5 - (-1)) / 4 = (5 + 1) / 4 = 6 / 4 = 1.5

因此，x = 5 对应的 z 分数为 1.5。

z = 1.5

这意味着在标准正态分布中，我们需要标出 z = 1.5 左侧 的区域，该区域对应于原始正态分布中 x < 5 的概率。

答题结果

您的选择: z = 1.5 左侧的区域

回答正确！您成功理解了z变换与概率区域对应关系。

题目解析

1. 原始正态分布：N(μ = -1, σ = 4)

2. 需要计算 P(X < 5)

3. 应用z变换：z = (5 - (-1)) / 4 = 1.5

4. 因此 P(X < 5) = P(Z < 1.5)

5. 在标准正态曲线上，应标出 z = 1.5 左侧的区域。
